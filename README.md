# StudyBuddy - Gamified Pomodoro Study Timer

A beautiful, gamified Pomodoro study timer web app designed to help students stay focused and build better study habits. Features an evolving character that grows as you complete study sessions!

## 🎨 Features

### Core Functionality
- **Pomodoro Timer**: 25-minute study sessions with 5/15-minute breaks
- **Character Evolution System**: Your study buddy evolves through 4 stages as you complete sessions
  - Stage 1 (Sprout): 0-10 sessions
  - Stage 2 (Seedling): 11-25 sessions
  - Stage 3 (Young Plant): 26-50 sessions
  - Stage 4 (Blooming): 51+ sessions
- **Progress Tracking**: Track daily and weekly study time
- **XP & Level System**: Earn 100 XP per completed session, level up every 500 XP
- **Study Streak**: Track consecutive days of studying

### Design
- Soft, pastel aesthetic with gentle gradient backgrounds
- Smooth animations and transitions
- iOS-optimized UI with bottom tab navigation
- 5 theme color options (Blue, Purple, Green, Peach, Beige)
- Rounded UI elements and clean typography

### Screens
1. **Timer Screen**: Main Pomodoro timer with character display and progress tracking
2. **Stats Screen**: Weekly progress charts, study session counter, and streak display
3. **Journal Screen**: Placeholder for future study notes and goals feature
4. **Settings Screen**: Customize timer durations, enable/disable sound, notifications, focus mode, and change themes

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## 🛠️ Tech Stack

- **React 19** with TypeScript
- **Vite** for fast development and optimized builds
- **Tailwind CSS v4** for styling with custom pastel theme
- **React Router** for navigation
- **LocalStorage** for data persistence

## 📱 Mobile Optimization

The app is optimized for mobile devices and ready to be wrapped with Capacitor for iOS deployment:
- Viewport configured for mobile browsers
- Apple mobile web app capable
- Safe area insets for notched devices
- Touch-friendly UI elements
